# EAN-8 в SVG — этап 1

Утилита командной строки читает из стандартного ввода семь цифр EAN-8
(контрольная цифра вычисляется автоматически) или полный восьмизначный код
(контрольная цифра проверяется). Результат сохраняется в указанный SVG-файл.
Веб-приложение и асинхронная обработка относятся к следующим этапам работы.

## Требования и запуск

Нужен Python 3.10 или новее. Сторонние пакеты не требуются. Сборка не нужна.

```sh
mkdir -p output
printf '2012345\n' | ./run.sh output/example.svg
```

Каталог для результата должен существовать. Также можно запустить
`python3 src/ean8.py output/example.svg`. При ошибке ввода программа печатает
сообщение в stderr, завершает работу с кодом 1 и не создаёт SVG.

## Функции и настройки

- `check_digit(payload)` вычисляет контрольную цифру семизначного кода.
- `normalize_ean8(value)` добавляет или проверяет контрольную цифру.
- `encode_ean8(value)` создаёт 67 модулей символа: защитные шаблоны,
  четыре цифры набора A и четыре цифры набора C.
- `render_svg(value)` создаёт SVG с белым фоном, чёрными штрихами,
  семимодульными свободными полями и подписью цифр.
- `main(argv)` читает stdin и записывает SVG по позиционному аргументу `output`.

Формат штрих-кода фиксирован: модуль 0,4 мм, ширина 81 модуль вместе со
свободными полями, высота обычных штрихов 50 модулей и защитных — 55.
Параметры заданы константами в `src/ean8.py`; конфигурационный файл не нужен.

## Четыре примера

Каждая команда сохраняет отдельный SVG в `output/` и выводит полный EAN-8.

```sh
mkdir -p output
printf '2012345\n' | ./run.sh output/example-1.svg
printf '9638507\n' | ./run.sh output/example-2.svg
printf '0000000\n' | ./run.sh output/example-3.svg
printf '1234567\n' | ./run.sh output/example-4.svg
```

Ожидаемые коды: `20123451`, `96385074`, `00000000`, `12345670`.
Можно передать полный проверенный код, например `20123451`.
